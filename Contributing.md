# Contributing to Trishul

Trishul is an independent C++ chess engine focused on aggressive play and high-performance search.

Contributions are welcome, especially from developers interested in:

* C++ and low-level optimization
* Chess-engine search
* NNUE evaluation
* Move generation and bitboards
* Multithreading
* Benchmarking and testing
* UCI implementation
* Engine strength improvements

## How to contribute

1. Check the open GitHub issues.
2. Choose an issue that matches your experience.
3. Discuss your proposed approach before making major changes.
4. Submit a pull request with a clear explanation of the change.
5. Include relevant testing or benchmark results.

## AI-assisted development

AI coding tools may be used as development aids, but contributors are responsible for understanding, testing, and maintaining the code they submit.

Pull requests containing unverified or unexplained generated code may be rejected.

## What matters most

Trishul values measurable improvements.

For engine-strength or performance changes, include benchmark results whenever practical.
