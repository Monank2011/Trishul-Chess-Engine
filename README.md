# Trishul-Chess-Engine
It is my hobby chess engine. 

When I started building it I never imagined it would become so strong but it surpassed my imagination and thus I am publishing it so other developers can help me make it even better.

I have added:
1. Modern PEXT bitboards
2. Opening book
3. Move Ordering
4. Quiescence Search
5. Delta Pruning
6. Negamax
7. Razoring
8. Null Move Pruning
9. Transposition Table
10. Killer Moves
11. Futility Pruning
12. Late Move Reduction
13. Principal Variation Search
14. Iterative Deepening
15. Lazy SMP

Minimum Requirements to use it:
1. Intel Core i3/i5/i7 4th Gen Haswell or newer architecture CPU.
2. AMD Excavator or newer architecture CPU.


I am extremely open to all the other developers to participate and help me with this project.
